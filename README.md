# ML Engineer's Knowledge Assistant

A multi-source, evidence-grounded Retrieval-Augmented Generation (RAG)
system for answering questions using official machine learning and
deep learning documentation.

## Initial Documentation Sources

- Scikit-learn: https://scikit-learn.org/stable/user_guide.html
- PyTorch: https://docs.pytorch.org/docs/stable/index.html
- Hugging Face: https://huggingface.co/docs
- TensorFlow: https://www.tensorflow.org/guide

## Project Status

Under active development.

## Planned Capabilities

- Multi-source documentation ingestion
- Structure-aware document parsing and chunking
- Local text embeddings and persistent vector storage
- Semantic retrieval
- Evidence-grounded answer generation
- Verifiable citations and answerability checks
- Evaluation using a curated question-answer benchmark

## Development

Python 3.12 and Conda are used for the development environment.
